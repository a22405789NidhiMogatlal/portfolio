1. Arquitetura MVT do Django

Desenho da Arquitetura

Componentes

  • Model: Representa os dados e a base de dados.
  • View: Trata da lógica e processa pedidos.
  • Template: Define o que o utilizador vê.

Fluxo de Informação

  1. O utilizador faz um pedido
  2. A View recebe o pedido
  3. A View consulta o Model
  4. O Model devolve os dados
  5. A View envia os dados para o Template
  6. O Template gera HTML
  7. A resposta é enviada ao utilizador

2. Modelação

Diagrama Entidade-Relação

models.py

class Licenciatura(models.Model):
    nome = models.CharField(max_length=255)

class UnidadeCurricular(models.Model):
    nome = models.CharField(max_length=255)
    licenciaturas = models.ManyToManyField(Licenciatura)

class Projeto(models.Model):
    titulo = models.CharField(max_length=255)
    uc = models.ForeignKey(UnidadeCurricular, on_delete=models.SET_NULL, null=True)

class Tecnologia(models.Model):
    nome = models.CharField(max_length=255)
    tipo = models.CharField(max_length=50)

Os modelos foram definidos utilizando Django ORM, permitindo representar as entidades da aplicação e as suas relações. Foram utilizadas relações do tipo ManyToMany e ForeignKey para modelar ligações entre entidades.
